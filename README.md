# JodJodKUB — เว็บจดรายรับรายจ่าย อ่านสลิปอัตโนมัติ

เว็บบันทึกรายรับรายจ่ายส่วนตัว มีระบบสมาชิก ข้อมูลของแต่ละคนแยกจากกัน เก็บลง PostgreSQL
อัปโหลดรูปสลิปแล้วระบบอ่านยอดเงิน วันเวลา และเลขอ้างอิงมาให้ ตรวจดูก่อนกดยืนยันบันทึก

## ต้องมีอะไรบ้าง

- Node.js 18 ขึ้นไป
- PostgreSQL (เวอร์ชัน 14 ขึ้นไป)

## ติดตั้งครั้งแรก

### 1. สร้างฐานข้อมูล

```bash
createdb -U postgres jodjodkub
```

ถ้าใช้ pgAdmin ก็สร้างฐานข้อมูลชื่อ `jodjodkub` จากหน้าจอได้เหมือนกัน

### 2. ตั้งค่าการเชื่อมต่อ

คัดลอก `server/.env.example` เป็น `server/.env` แล้วแก้ `DATABASE_URL` ให้ตรงกับเครื่องคุณ

```
DATABASE_URL=postgres://postgres:รหัสผ่านของคุณ@localhost:5432/jodjodkub
JWT_SECRET=ข้อความสุ่มยาว ๆ
```

> ถ้า PostgreSQL ของคุณไม่ได้อยู่พอร์ต 5432 ให้เปลี่ยนเลขพอร์ตในบรรทัดนั้นด้วย

### 3. ติดตั้งไลบรารีแล้วรัน

```bash
cd server
npm install
npm start
```

เปิดเบราว์เซอร์ไปที่ **http://localhost:3000** แล้วสมัครสมาชิกได้เลย
ตารางในฐานข้อมูลถูกสร้างให้อัตโนมัติตอนเซิร์ฟเวอร์บูตครั้งแรก

### 4. ตั้งแอดมิน (ถ้าต้องการ)

สมัครสมาชิกในเว็บก่อน แล้วรัน

```bash
npm run seed:admin -- อีเมลของคุณ@example.com
```

## ฟีเจอร์

| ส่วน | รายละเอียด |
|---|---|
| สมาชิก | สมัคร / เข้าสู่ระบบ / เปลี่ยนรหัสผ่าน — รหัสผ่านเก็บแบบ bcrypt |
| แยกข้อมูล | ทุกคำสั่งกรอง `user_id` ของผู้ล็อกอิน ไม่มีทางเห็นข้อมูลคนอื่น |
| อ่านสลิป | อัปโหลดรูป → OCR (Tesseract ภาษาไทย+อังกฤษ) → เติมค่าให้ → ผู้ใช้ยืนยันเอง |
| กันซ้ำ | จำเลขอ้างอิงของสลิป อัปใบเดิมซ้ำจะเตือนและไม่บันทึกซ้ำ |
| งบประมาณ | ตั้งงบรวมทั้งเดือนหรือแยกรายหมวด มีแถบเตือน เขียว/เหลือง/แดง |
| รายงาน | กราฟ 12 เดือน กราฟรายวัน และกราฟวงกลมแยกหมวด |
| ส่งออก | ดาวน์โหลด CSV เปิดใน Excel อ่านภาษาไทยได้ |
| แอดมิน | ดูรายชื่อสมาชิก ตั้งรหัสผ่านใหม่ เปลี่ยนบทบาท ลบบัญชี — **แต่ดูรายการเงินของคนอื่นไม่ได้** |

## เรื่องที่ควรรู้เกี่ยวกับการอ่านสลิป

- **ครั้งแรกที่อ่านสลิปต้องต่ออินเทอร์เน็ต** เพื่อโหลดไฟล์ภาษาไทยของ Tesseract (~10MB)
  หลังจากนั้นไฟล์ถูกเก็บไว้ใน `server/tessdata/` แล้วใช้งานออฟไลน์ได้
- ความแม่นของ OCR อยู่ราว 80–90% สลิปที่ถ่ายเอียง เบลอ หรือมีแสงสะท้อนอาจอ่านผิด
  ระบบจึงบังคับให้ผู้ใช้ตรวจสอบและแก้ไขก่อนกดยืนยันเสมอ
- รูปสลิปเก็บไว้ที่ `server/uploads/<เลขสมาชิก>/` เปิดดูย้อนหลังได้จากลิงก์ในตารางรายการ

## โครงสร้างโปรเจค

```
server/
├─ src/
│  ├─ index.js       ตั้งค่าเซิร์ฟเวอร์ เสิร์ฟหน้าเว็บ ต่อ route
│  ├─ db.js          เชื่อม PostgreSQL + สร้างตารางอัตโนมัติ
│  ├─ auth.js        รหัสผ่าน, JWT, ตรวจสิทธิ์
│  ├─ ocr.js         อ่านข้อความและ QR จากรูป
│  ├─ parseSlip.js   แปลงข้อความสลิปเป็น ยอดเงิน/วันเวลา/เลขอ้างอิง
│  ├─ seedAdmin.js   ตั้งสมาชิกเป็นแอดมิน
│  └─ routes/        auth, admin, entries, slips, summary, budgets, export
└─ client/
   ├─ index.html     หน้าเข้าสู่ระบบ / สมัครสมาชิก
   ├─ app.html       หน้าแอปหลัก
   ├─ css/style.css
   └─ js/            api, login, app, slip, budget, report, admin
```

## ตารางในฐานข้อมูล

- `users` — สมาชิก (email, display_name, password_hash, role)
- `entries` — รายการเงิน (type, amount, category, note, occurred_at, slip_id, txid)
- `slips` — รูปสลิปที่อัปโหลดพร้อมข้อความที่ OCR อ่านได้
- `budgets` — งบประมาณรายเดือน (month, category, amount)
